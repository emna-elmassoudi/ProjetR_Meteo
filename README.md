# ProjetR_Meteo — Analyse des normales climatiques (1961–1990) — Tunisie

## Objectif
Analyser la saisonnalité des températures et des précipitations en Tunisie sur la période 1961–1990.

## Données
- Dataset : normales climatiques (1961–1990)
- Variables :
  - tmm : température moyenne
  - tnm : température minimale
  - txm : température maximale
  - rrtm : précipitations

## Méthodologie
- Nettoyage des données avec R
- Analyse descriptive
- Visualisations (ggplot2)
- Rapport (Quarto : .qmd)

## Structure du dépôt
- data/ : données (raw / clean)
- scripts/ : scripts R (nettoyage, analyse)
- reports/ : rapport Quarto
- slides/ : présentation (PDF/PPT)

## Exécution
Ouvrir le projet dans RStudio et lancer le rendu du fichier Quarto dans `reports/`.

## Liens
- Rapport (Quarto) : `reports/index.qmd`
- Slides : `slides/presentation.pdf`
