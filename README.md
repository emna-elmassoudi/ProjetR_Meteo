# Capstone Project – Analyse climat Tunisie (1961–1990)

## Objectif du projet
Ce projet analyse les normales climatiques mensuelles en Tunisie
sur la période 1961–1990, en se concentrant sur les températures
et les précipitations afin d’étudier la saisonnalité du climat.

## Données
Les données proviennent de sources open data (Data Tunisie /
Institut National de la Météorologie).

Variables analysées :
- Température moyenne (tmm)
- Température minimale (tnm)
- Température maximale (txm)
- Précipitations (rrtm)
# ProjetR_Meteo — Analyse des normales climatiques (1961–1990) — Tunisie

## Objectif

*Outils utilisés : R, tidyverse, Quarto.*
Analyser la saisonnalité des températures et des précipitations en Tunisie sur la période 1961–1990.

## Données
- Dataset : normales climatiques (1961–1990)
- Variables :
  - tmm : température moyenne
  - tnm : température minimale
  - txm : température maximale
  - rrtm : précipitations

## Méthodologie
- Nettoyage des données avec R
- Analyse descriptive
- Visualisations (ggplot2)
- Rapport (Quarto : .qmd)

## Structure du dépôt
- data/ : données (raw / clean)
- scripts/ : scripts R (nettoyage, analyse)
- reports/ : rapport Quarto
- slides/ : présentation (PDF/PPT)

## Exécution

*Les scripts R sont disponibles dans le dossier `scripts/`.*
Ouvrir le projet dans RStudio et lancer le rendu du fichier Quarto dans `reports/`.
